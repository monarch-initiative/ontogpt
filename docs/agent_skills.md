# Agent Skills

OntoGPT ships four [Agent Skills](https://agentskills.io) under [`skills/`](https://github.com/monarch-initiative/ontogpt/tree/main/skills) in the repository. A skill is a directory with a `SKILL.md` file that an AI coding agent (Claude Code, Codex, Cursor, and others that implement the format) loads when a task matches its description. Together they let an agent run OntoGPT for you: choose or write an extraction template, pick the ontologies to ground to, run the extraction, and work out why a value did not ground.

| Skill | Covers |
|---|---|
| `ontogpt-extract` | installing, credentials, choosing a model, `ontogpt extract` and the literature commands, reading and converting results |
| `ontogpt-select-template` | matching a goal and a text to a bundled template; a catalog of all templates with their grounding prefixes; a script that prints exactly what a template asks the model and how it grounds each entity |
| `ontogpt-author-template` | writing a new LinkML template: header, classes, prompts, enums; a guide from entity type to ontology and OAK annotator; a skeleton; a validator that catches the usual mistakes before a run |
| `ontogpt-troubleshoot` | a symptom table for run errors, parsing defects, grounding defects, and cache confusion, organized by the stage of the pipeline that failed |

## Using them

In a Claude Code session opened in the OntoGPT repository the skills are already registered through `.claude/skills/`. Elsewhere, copy or symlink the four directories into your agent's skills location, for example `~/.claude/skills/` for Claude Code. See [`skills/README.md`](https://github.com/monarch-initiative/ontogpt/blob/main/skills/README.md) for other agents.

Then ask in plain language. Some requests that activate them:

- "Extract the phenotypes and diagnoses from these case reports with OntoGPT."
- "Which OntoGPT template should I use for drug mechanism triples from PubMed abstracts?"
- "Write an OntoGPT template for soil sampling metadata grounded to ENVO."
- "Half the diseases came back as AUTO: ids. Why?"

## What the skills assume

The agent needs the `ontogpt` command on its path, an LLM credential in the environment, and network access the first time an ontology annotator is used. The helper scripts (`describe_template.py`, `validate_template.py`) import `ontogpt` and must run in the same environment, for example with `uv run python`.

## Contributing

Edit the `SKILL.md` and `references/` files as you would documentation. The template catalog is generated by `util/gen_skill_template_catalog.py`; rerun it after adding a template.
